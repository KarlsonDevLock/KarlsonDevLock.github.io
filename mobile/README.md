# KarlDev Portfolio — Expo (React Native)

Native rewrite of the portfolio website. Same screens, same assets, same visual
design — only the code environment changed (HTML/CSS/JS → React Native).

## Run it

```bash
cd mobile
npm install
npx expo start
```

Then:

- **Phone:** install **Expo Go**, scan the QR code.
- **Android emulator:** press `a`.
- **iOS simulator (macOS):** press `i`.
- **Browser:** press `w`.

The website assets are copied from the repo root `assets/` into
`mobile/assets/portfolio/` automatically before every start/build
(`scripts/sync-assets.mjs`). The copy is gitignored so the repo does not store
85 MB twice.

## Screens

| Route | File | Content |
| --- | --- | --- |
| `/` | `src/app/index.jsx` → `src/screens/HomeScreen.jsx` | hero video, project carousel, about, footer |
| `/projects/games` | `src/app/projects/games.jsx` | 6 game projects |
| `/projects/mobile` | `src/app/projects/mobile.jsx` | 1 mobile project |
| `/projects/web` | `src/app/projects/web.jsx` | 2 website projects |

Navigation uses **Expo Router** (a native stack). The header, carousel and
footer are shared components.

## How the site was ported

| Website | React Native |
| --- | --- |
| `position: fixed` header | absolutely positioned header + `useSafeAreaInsets` |
| CSS radio-button carousel | `useState` index + `Animated.timing` (520 ms, same cubic-bezier) |
| per-slide gradient background | `expo-linear-gradient` |
| `backdrop-filter: blur()` | `expo-blur` (full blur on iOS; translucent panel on Android) |
| `clamp()` typography | `clamp()` helper in `src/theme.js`, sizes in dp |
| `@media (max-width: 900px / 640px)` | `useLayout()` breakpoints (`isTablet`, `isPhone`) |
| `<video autoplay muted loop playsinline>` | `expo-video` `useVideoPlayer` + `VideoView` |
| CSS keyframe photo/logo cross-fade | `Animated.loop` with the same 10 s timeline |
| `#home`, `#about` anchors | measured section offsets + `ScrollView.scrollTo` |
| 3 project category pages | 3 routes with one shared `ProjectsScreen` |

## Known differences (and why)

- **Hero vignette:** the original uses `radial-gradient`; `expo-linear-gradient`
  cannot do radial, so the hero uses the same top-to-bottom darkening only.
- **Fonts:** the site declares `font-family: Inter` but never loads an Inter
  webfont, so visitors see the system UI font. The app uses the system font too
  — identical result, nothing to download.
- **Posters:** the original HTML points at `assets/images/projects/*.svg`, which
  do not exist in the repo, so no posters are used (same broken reference is
  simply dropped).
- **Android blur:** without a `BlurTargetView`, `expo-blur` renders a
  semi-transparent panel instead of a live blur. The panels already use the same
  translucent fallback colours as the CSS.
- **Videos:** 85 MB total. Play Store limits new apps to 100 MB, so compress or
  trim the clips before an EAS/store build. For the course demo, Expo Go is fine.
- **Store identity:** `app.json` sets name/slug/scheme (`karldev`). Bundle
  identifiers (`ios.bundleIdentifier`, `android.package`) are still unset — add
  them before `eas build`.

## Project layout

```
src/
  app/                 Expo Router routes only
    _layout.jsx        native stack + safe-area provider
    index.jsx          home route
    projects/*.jsx     category routes
  screens/             screen implementations
  components/          header, carousel, showcase, profile, footer, video
  data/projects.js     all copy + require()d assets
  theme.js             colours, radii, clamp(), useLayout()
assets/portfolio/      generated by scripts/sync-assets.mjs (gitignored)
scripts/sync-assets.mjs
```

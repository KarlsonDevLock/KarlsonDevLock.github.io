KARLDEV PORTFOLIO — HTML + CSS ONLY

Open index.html to start.

Main files:
- index.html                 Home portfolio
- projects-games.html        Game projects
- projects-mobile.html       Mobile projects
- projects-web.html          Website projects
- style.css                  All styling and customization comments

Easy edits:
1. Replace assets/videos/hero-bg.mp4 with your intro background video.
2. Replace assets/videos/project-placeholder.mp4 references in each project page with your project recordings.
3. Replace assets/images/profile-placeholder.svg with your 2x2 photo and update the src in index.html if the filename changes.
4. Replace project placeholder SVGs in assets/images/projects/ with your real project images/logos.
5. Change project names and descriptions directly in the HTML pages.
6. Replace the placeholder email in index.html: your-email@example.com.
7. Edit the color variables at the top of style.css. The three home slider gradients are separately configurable there.

No JavaScript is included. The project carousel and profile slideshow are CSS-only.
